# BÁO CÁO KIỂM TOÁN UI/UX — WEBSITE CÁ'S HOA

- **Nhánh làm việc:** `feature/ui-professional-polish` (tách từ `main` tại `9cb1b9955296b2e5f856373d590097f8410376c5`)
- **Ngày kiểm toán:** 19/11/2026
- **Phạm vi:** 19 trang Storefront PHP, 24 route Admin PHP, 4 tệp CSS, 7 tệp JS render/tương tác khách hàng (kiểm cả HTML sinh động từ JS). Không thay đổi nghiệp vụ PHP, SQL, database, auth, order, inventory, CSRF hay cấu trúc API.

## 1. Kết luận tổng quan

Giao diện sau khi hợp nhất backend đã có bộ token màu nhận diện rõ ràng (xanh sage + kem ngà + hồng đào nhẹ, font `Lora` + `Be Vietnam Pro`) và vận hành ổn định, nhưng tồn tại sự phân mảnh rõ rệt giữa các cụm tính năng:
1. **Storefront**: Một số trang dùng class tùy biến chưa đồng bộ với design system (FAQ dùng màu xanh mặc định của Bootstrap, trang `tu-van-hoa.php` chứa khối `<style>` nội tuyến riêng, `index.php` ẩn `<h1>` bằng `.visually-hidden`, `tra-cuu-don-hang.php` lệch hàng input do `.form-text`, thanh điều hướng thiếu active state theo loại/trang).
2. **Admin**: Có hai lớp layout (`admin/_app.php` và `admin/_ops.php`) dùng CSS CDN và chứa các đoạn `<style>` nội tuyến lặp lại, ghi đè mất hành vi drawer mobile của `assets/css/admin.css`; thang chữ bảng/nhãn quá nhỏ (`8px–10px`), độ tương phản của nút `.admin-btn` (`3.76:1`) và badge `.admin-status` (`3.25:1–3.82:1`) chưa đạt WCAG AA (`4.5:1`), nhiều ô lọc/nhập trong bảng thiếu `aria-label`/`for-id`, và ở lần chụp kiểm chứng mobile `375px` phát hiện topbar bị rớt dòng đè lên tiêu đề trang.

Toàn bộ vấn đề **P0** và **P1** cùng phần lớn **P2** đã được xử lý trực tiếp trong mã nguồn UI/CSS/JS và kiểm chứng lại trên trình duyệt Chrome Headless với 7 kích thước màn hình (`320 / 375 / 390 / 768 / 1024 / 1440 / 1920 px`).

## 5. Rủi ro và lưu ý còn lại

1. **Tải Google Fonts**: Cả `style.css` và `admin.css` vẫn dùng `@import url('https://fonts.googleapis.com/...')` cho `Be Vietnam Pro` và `Lora`. Khi không có mạng Internet, trình duyệt tự fallback sang `system-ui` / `Georgia` (an toàn, không lỗi trang).
2. **Các tệp `.html` tĩnh cũ từ Yêu cầu 1**: Vẫn tồn tại trong repo để tham chiếu nhưng hệ thống PHP/MySQL hiện tại không dẫn link sang `.html`; không chỉnh sửa hàng loạt các file `.html` cũ để tránh nhiễu diff.
3. **Môi trường MySQL 8.0 & email Internet**: Kiểm thử UI đợt này chạy trên MariaDB 10.4.32 (XAMPP) cổng `3307` biệt lập; luồng gửi email khôi phục mật khẩu ra Internet và bộ CI MySQL 8.0 trên GitHub Actions chưa được kích hoạt trong đợt nâng cấp UI cục bộ.
4. **Dữ liệu kiểm thử mẫu trong `products` / `wrapping_colors`**: Seed gốc chưa có dòng `product_wrapping` nên khi xem UI chi tiết giấy gói cần có bản ghi gán giấy gói (trong XAMPP nhóm có thể gán trực tiếp ở màn hình `admin/giay-goi.php`).
