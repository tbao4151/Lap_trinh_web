# CÁ'S HOA — Đồ án Lập trình Web

Website bán hoa tươi được xây dựng cho đồ án môn Lập trình Web.

## Công nghệ
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- LocalStorage cho dữ liệu demo phía trình duyệt

## Các trang hiện có

### Batch 1 — Storefront cốt lõi
1. `index.html`
2. `san-pham.html`
3. `chi-tiet-san-pham.html`
4. `gio-hang.html`
5. `thanh-toan.html`

### Batch 2 — Đặt hàng và tài khoản
6. `dat-hang-thanh-cong.html`
7. `tra-cuu-don-hang.html`
8. `dang-nhap.html`
9. `dang-ky.html`
10. `quen-mat-khau.html`

### Batch 3 — Tài khoản và nội dung

12. `lich-su-don-hang.html`
13. `gioi-thieu.html`
14. `lien-he.html`

## Cấu trúc
- `assets/css/`
- `assets/js/`
- `assets/images/` — ảnh PNG lưu trực tiếp trong project

## Chạy local
Mở `index.html` bằng VS Code Live Server.

## Giai đoạn BackEnd
Các chức năng xác thực, lưu đơn, quản lý sản phẩm và dữ liệu người dùng sẽ được xử lý bằng PHP và MySQL/MariaDB.
