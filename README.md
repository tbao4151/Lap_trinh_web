# CÁ'S HOA — Đồ án Lập trình Web

Website bán hoa tươi được xây dựng cho đồ án môn Lập trình Web.

## Công nghệ
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- LocalStorage cho dữ liệu demo phía trình duyệt

## Các trang hiện có

### Batch 1 — Storefront cốt lõi
1. `index.html` — Trang chủ
2. `san-pham.html` — Danh sách và lọc sản phẩm
3. `chi-tiet-san-pham.html` — Chi tiết sản phẩm
4. `gio-hang.html` — Giỏ hàng
5. `thanh-toan.html` — Thanh toán / thông tin nhận hoa

### Batch 2 — Đặt hàng và tài khoản
6. `dat-hang-thanh-cong.html` — Xác nhận đơn demo
7. `tra-cuu-don-hang.html` — Tra cứu đơn bằng mã đơn và SĐT người nhận
8. `dang-nhap.html` — Đăng nhập
9. `dang-ky.html` — Đăng ký
10. `quen-mat-khau.html` — Khôi phục mật khẩu

## Cấu trúc
- `assets/css/` — CSS dùng chung và responsive
- `assets/js/` — JavaScript xử lý giao diện và dữ liệu demo
- `assets/images/` — Ảnh sản phẩm lưu trực tiếp trong project

## Chạy local
Mở `index.html` bằng VS Code Live Server.

## Giai đoạn BackEnd
Các chức năng xác thực, lưu đơn hàng, quản lý sản phẩm và dữ liệu người dùng sẽ được xử lý bằng PHP và MySQL/MariaDB.
