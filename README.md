# CÁ'S HOA — Đồ án Lập trình Web

Website bán hoa tươi được xây dựng cho đồ án môn Lập trình Web.

## Công nghệ
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- LocalStorage cho giỏ hàng demo

## Batch 1 — FrontEnd cốt lõi
1. `index.html` — Trang chủ
2. `san-pham.html` — Danh sách và lọc sản phẩm
3. `chi-tiet-san-pham.html` — Chi tiết sản phẩm
4. `gio-hang.html` — Giỏ hàng
5. `thanh-toan.html` — Thanh toán / thông tin nhận hoa

## Cấu trúc
- `assets/css/` — CSS dùng chung và responsive
- `assets/js/` — JavaScript xử lý giao diện và giỏ hàng
- `assets/images/` — Ảnh sản phẩm lưu trực tiếp trong project

## Chạy local
Mở `index.html` bằng VS Code Live Server.
